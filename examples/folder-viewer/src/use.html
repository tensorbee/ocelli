Use the library

This folder viewer is not the wasm path. Nothing is published. The three calls below are the library. The window arithmetic lives once, in LutChain, and this page does not copy it.

JavaScript

Create a viewport id and pack commands for that id. Decoded pixels stay in the worker. DicomwebClient takes studiesServiceUrl, wadoUriUrl, fetch, the wasm memory and a sink.

import { viewportId, packCommands, DicomwebClient } from "@ocelli/core";

const id = viewportId(1);
const bytes = packCommands(id, []);

React

Mount one viewport. Pass the session you own. Null means there is no session yet.

import { viewportId } from "@ocelli/core";
import { OcelliViewport } from "@ocelli/react";

<OcelliViewport id="view" viewport={viewportId(1)} session={null} />

Rust

Parse a Part 10 object with parse_part10, then map stored pixels with LutChain. The workspace README section "Use the library" shows the path dependencies. This page does not paste a window formula.
