More than this image

This page names library behaviour the image does not draw. There is no picture here and there is no stand-in result. The example page started with npm run dev is where those controls run.

Overlay and shutter

Overlay planes and display shutters are read by the library. The example page shows a hit and a hide. This image does not draw either one.

Between slices

Nearest and linear blending between slices is stack interpolation. The example page shows both. This image shows one slice and does not blend it with the next.

Reference line

A reference line and a reference cursor belong to the example page. This image does not draw a line from another series.

Several series at once

A tilted pair, prior studies, linked scroll and a synced window are named on the example page. This image does not build them.

MPR, slab, volume and fusion

MPR, slab, volume rendering and fusion are named on the example page. This image does not build them.

One to one, histogram, metadata and preferences

One to one, histogram, a metadata browser and preferences read unavailable on the example page. This image does not invent a result for them.

Worker decode

The wasm path posts one WADO-RS instance to a worker and keeps the pixels there. This folder viewer posts the file to the local process. It is not that path.

Documents

TID 1500, saving and loading a measurement, undo, a key object and a secondary capture live in @ocelli/core. The example page calls them. A key image flag on the image page is only a mark in this session. It does not write a Key Object Selection and it is not saved.
