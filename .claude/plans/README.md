# Design plans

One file per F-ID, `F-XXX-design.md`, written by `/design` and tracked in git.

A plan is the contract for a story. Its `## Normative source, transcribed`
section quotes the HLD sections the story implements, because a plan that
paraphrases a formula has already lost the detail the formula existed to carry.

These are agent-neutral. Claude Code and Codex read and write the same files.
