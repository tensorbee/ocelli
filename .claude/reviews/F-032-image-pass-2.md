## Smells

### S1, the tier `ImageCache` fixes is asserted by no test

**Where**: `crates/ocelli-cache/src/image.rs:221`, against `crates/ocelli-cache/tests/image_cache.rs:292` to `crates/ocelli-cache/tests/image_cache.rs:293`
**What**: `ImageCache::new` fixes the tier to `CacheTier::Decoded`. The read-side test added for pass 1 S1 asserts `pressure().used` and `pressure().budget` and never asserts `pressure().tier`. No test in the image cache file names the tier field at all.
**Why it matters**: The tier is the one `Pressure` field this type itself chooses. It is also the field F-034 telemetry will read to attribute pressure to a tier. The behaviour is correct today. A wrong variant here ships green, which is the never-reached class that survives a green suite.
**Evidence**: changed `CacheTier::Decoded` to `CacheTier::Encoded` at `crates/ocelli-cache/src/image.rs:221` and ran `bin/ocelli.sh test ocelli-cache --test image_cache`. Result was 11 passed and exit 0. The mutation was reverted exactly and the line was read back as `CacheTier::Decoded`. A search for a tier assertion in `crates/ocelli-cache/tests/image_cache.rs` returned no hit.
